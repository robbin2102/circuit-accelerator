# The Panel

Five agents, five investor mandates, one rubric. Every Thursday during Circuit, each team's narrative artifact goes to the panel; each persona returns a score, its single biggest objection, and the one question it would ask you at dinner.

The mix roughly mirrors the investor types at Circuit's dinners and in the SEA market: institutional VC, corporate VC, crypto-native fund, angel, family office. Personas are composites built on real mandate logic — **no persona represents a real individual or firm.**

## How to run a scoring session

1. Fresh conversation, one persona at a time (never all five in one chat — they contaminate each other).
2. Paste the persona file + `rubric.md` as instructions.
3. Attach: the team's narrative artifact for the week (Friday post draft, narrative doc, or pitch transcript) **plus** their manifest, **plus last week's artifact** for the pairwise comparison.
4. Collect the structured output (defined in rubric.md). Log scores in the cohort Notion.
5. Repeat per persona. Aggregate: median score per axis, all five objections listed verbatim.

Founders can also self-serve any persona at any time as a sparring partner — that's encouraged, and it's the Week 4 podcast rehearsal tool.

## Honest limitations — read before trusting a number

LLM judges are noisy. This design compensates; it doesn't cure:

- **Absolute scores drift** between runs and model versions. Pin the model version for the whole programme. Re-anchor if the provider force-upgrades.
- **The signal is trajectory, not ranking.** Week-over-week movement on a team's own narrative is meaningful; cross-team score comparison is mostly noise plus company-stage differences. Do not publish a leaderboard.
- **Pairwise beats absolute.** The rubric's "stronger/weaker than last week, and why" verdict is the most reliable output. Weight it over the numbers.
- **Sycophancy is the failure mode.** If a persona's scores only go up, it's drifting toward flattery — re-anchor against the worked examples in rubric.md.
- **Human calibration:** Kitty/Lani spot-check ≥2 scored artifacts per week against their own judgment. If human and panel disagree twice in a row on the same axis, fix the rubric anchors, not the human.

Position to founders exactly as: *directional pressure-testing from five investor mindsets — not a prediction of any real investor's behaviour.*

## Week 3 twist

Each team builds a sixth persona: **their own ICP** (from `manifest/icp.md`), in the same format as the five here. Best ones get added to the shared panel. Writing a convincing investor persona forces exactly the mandate-level understanding that good targeting requires — the exercise is the point.
